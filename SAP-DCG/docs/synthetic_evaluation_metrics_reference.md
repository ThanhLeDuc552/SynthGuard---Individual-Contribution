## 1. Unified Evaluation Metrics Matrix (Metrics, Meaning, References & Links)

> **Scope Note:** All suitable post-generation metrics from `ids_generative_metrics_summary-v2.xlsx` (26 existing tabular/IDS/flow metrics + 11 newly researched Reliability, Balance, and NetFlow Protocol Validity metrics = **37 applicable metrics**) are combined below. Two non-tabular/training-time items from the workbook (`FID` for image embeddings and `Formal (ε, δ)-DP` requiring DP-SGD/PATE training) and LLM/text-only pre-training metrics (`FastText`, `Perplexity`, `Min-K%`, `PETAL`, `MIWV`, `DeMix`, `Zlib`) are excluded from this NetFlow reference table.
