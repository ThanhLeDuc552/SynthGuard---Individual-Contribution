# SAP-DCG: Suggested Fixes for Synthetic Distribution Shift & Protocol Invalidity

This document summarizes the root causes of the synthetic-vs-real distribution shift observed in [`notebooks/synthetic_metrics_evaluation.ipynb`](../notebooks/synthetic_metrics_evaluation.ipynb) (`CTGAN result_2` and `TVAE result_2`) and [`docs/current problem.txt`](current%20problem.txt), along with concrete **Data**, **Filter**, and **Model** fixes.

## 1. Data & Feature-Representation Fixes (Highest ROI)

### 1.1 Fix Feature Typing (`TVAEPreprocessor` & `NetFlowPreprocessor`)
- **Problem:** `ICMP_TYPE` is currently in `log_cols` (continuous) instead of `code_cols` (categorical) in [`components/tvae_generator.py`](../components/tvae_generator.py), causing `ICMP_TYPE == 0 when TCP/UDP` to pass only `17.2%` of the time in TVAE. Similarly, `TCP_WIN_MAX_IN` and `TCP_WIN_MAX_OUT` behave like spiky OS stack constants (`0`, `255`, `1024`, `8192`, `65535`, etc.) rather than smooth continuous distributions.
- **Fix:**
  - Move `ICMP_TYPE`, `ICMP_IPV4_TYPE`, and `DNS_QUERY_TYPE` into discrete/categorical columns.
  - Encode spiky integer columns (`TCP_WIN_MAX_IN`, `TCP_WIN_MAX_OUT`) as top-$K$ discrete codes + `"OTHER"` residual (or categorical bins) rather than unconstrained continuous values.
  - Replace plain `log1p` on heavy-tailed continuous columns with `QuantileTransformer(output_distribution="normal")` or RDT `GaussianNormalizer`.

### 1.2 Handle Near-Constant & Zero-Inflated Columns Explicitly
- **Problem:** Neural generators smear exact zeros into small non-zero noise:
  - `DST_TO_SRC_IAT_MIN`: `100.00%` zero in real attacks (`1` unique value) vs. `82.54%` zero in TVAE (`874` unique values).
  - `DURATION_OUT`: `26.98%` zero in real vs. `9.06%` in TVAE.
  - `SRC_TO_DST_SECOND_BYTES`: `15.58%` zero in real vs. `1.58%` in TVAE.
- **Fix:**
  - **Constant / near-constant columns** (e.g., `DST_TO_SRC_IAT_MIN` when variance $\approx 0$): freeze during generation and restore the constant value on inverse transform.
  - **Zero-inflated continuous columns:** Use a **two-part (hurdle) representation** — a binary categorical flag `col_is_zero` plus a log-transformed positive magnitude, masking `col = 0` whenever `col_is_zero == 1`.

### 1.3 Reparameterize Coupled & Derived NetFlow Features
- **Problem:** `LONGEST_FLOW_PKT <= MAX_IP_PKT_LEN` fails on `82.3%` of CTGAN rows and `45.4%` of TVAE rows because both are generated independently.
- **Fix:**
  - Generate **non-negative deltas** instead of independent bounds so ordering invariants hold **by construction**:
    - Generate `MIN_TTL` and $\Delta_{\text{TTL}} \ge 0$ $\rightarrow$ `MAX_TTL = MIN_TTL + delta`.
    - Generate `SHORTEST_FLOW_PKT`, $\Delta_1 \ge 0$, $\Delta_2 \ge 0$ $\rightarrow$ `LONGEST_FLOW_PKT = SHORTEST + delta_1`, `MAX_IP_PKT_LEN = LONGEST + delta_2`.
  - Recompute deterministic derived columns (e.g., `SRC_TO_DST_AVG_THROUGHPUT`, `DST_TO_SRC_AVG_THROUGHPUT`, `SECOND_BYTES`) from generated bytes and duration rather than sampling them independently.

### 1.4 Replace Aggressive `30x` SMOTE-NC Pre-Balancing
- **Problem:** In [`orchestration/pipeline_orchestrator.py`](../orchestration/pipeline_orchestrator.py#L248-L250), Round 2 trains the generator on `SMOTE-NC`-oversampled attacks (`y_max=30` $\Rightarrow$ `Worms` has `79` real vs. `2,370` SMOTE rows = `96.7%` linear interpolations), which smears exact zeros and non-linear protocol boundaries before the generator ever sees the data.
- **Trade-off Warning:** Simply dropping SMOTE-NC while keeping isolated per-class `TVAESynthesizer` (`300` epochs, `dims=(128,128)`) on `79` rows risks **memorization** (`DCR Closer-to-Train` $\to 100\%$) or **mode collapse**.
- **Fix (Choose one):**
  1. **Light, structure-preserving SMOTE-NC:** Restrict pre-augmentation to ultra-rare classes ($n_c < 500$) at a mild ratio (`2x–3x`, not `30x`), applied **only after** fixing feature typing, hurdle zero-indicators, and delta reparameterization.
  2. **Shared-representation transfer learning:** Pretrain one conditional generator on **all `55,612` real attack flows** (learning valid NetFlow grammar), then briefly fine-tune per rare class with stronger regularization and validation early stopping.

## 2. Filter Fixes (`components/synthetic_sample_filter.py`)

### 2.1 Complete & Enforce NetFlow Protocol Invariants
- Add the missing rules to `apply_reverse_transform_and_rules()`:
  - `ICMP_TYPE = 0` and `ICMP_IPV4_TYPE = 0` whenever `PROTOCOL in [6, 17]`.
  - Enforce `LONGEST_FLOW_PKT <= MAX_IP_PKT_LEN`, `IN_BYTES >= IN_PKTS` (when `IN_PKTS > 0`), and `OUT_BYTES >= OUT_PKTS` (when `OUT_PKTS > 0`).
- **Prefer rejection over heavy clamping:** Clamping severely invalid rows creates artificial boundary pile-ups that C2ST detects; reject rows that fail hard protocol invariants instead.

### 2.2 Local Manifold-Support Distance Gate (in `signed_log1p` Space)
- **Problem:** `enn_filter()` currently uses raw `StandardScaler` Euclidean distance (dominated by heavy-tailed byte/duration columns) and only checks **class label agreement** among 3 neighbors, not **distance** — so far off-manifold outliers still pass.
- **Fix:**
  - Compute distances in **`signed_log1p` + `StandardScaler` space** (matching Metrics 6 & 11).
  - Add a **local density-adaptive $k$-NN radius gate**: keep `x_syn` only if `dist(x_syn, nn_real_same_class) <= alpha * r_k(nn_real_same_class)` (or below a per-class real intra-class NN distance quantile such as `p90`/`p95`).

### 2.3 C2ST / Density-Ratio Rejection Sampling
- Train a lightweight real-vs-synthetic discriminator $D(x)$ and either reject samples with $P(\text{syn} \mid x) > \tau_{\text{real}}$ or resample with importance weights $\propto \frac{1 - D(x)}{D(x)}$ to directly drive C2ST ROC-AUC down toward `0.50`.

## 3. Model & Tuning Fixes

### 3.1 Capacity & Early-Stopping Regularization Scaled to $n_c$
- Do not use the same `epochs=300` and `(128, 128)` width for both `n=79` (`Worms`) and `n=10,000`.
- Hold out `15%–20%` of each class's real flows for internal validation early stopping to prevent memorization on rare classes, and increase KL / `l2scale` regularization when $n_c < 1,000$.

### 3.2 Protocol-Conditioned Generation
- Condition generation explicitly on `(Attack, PROTOCOL)` (or route TCP, UDP, and ICMP/Other through separate conditional branches) so TCP-only and ICMP-only fields never cross-contaminate.

### 3.3 Benchmark Tree / Diffusion Tabular Generators
- Standard CTGAN/TVAE struggle with sharp mixed-type NetFlow tables (exact zeros, discrete OS constants, conditional flags).
- Benchmark **Adversarial Random Forests (ARF)**, **ForestDiffusion**, or **TabDDPM / TabSyn** against CTGAN/TVAE in [`notebooks/synthetic_metrics_evaluation.ipynb`](../notebooks/synthetic_metrics_evaluation.ipynb); tree/diffusion tabular generators naturally preserve axis-aligned thresholds, exact zeros, and conditional protocol rules.

### 3.4 Composite Tuning Objective (Rounds 1–3)
- Currently Round 1 optimizes `val macro_f1` alone. Add a fidelity/validity penalty so the tuner does not pick `y_max` values with high distribution shift:
  $$\text{Score} = \text{Val Macro F1} - \lambda_1 \cdot \text{Mean KS} - \lambda_2 \cdot (1 - \text{PFIR})$$

---

## 4. Recommended Implementation Order

1. **Quick Wins (Data + Filter):** Freeze near-constant columns (`DST_TO_SRC_IAT_MIN`), move `ICMP_TYPE`/`ICMP_IPV4_TYPE` & spiky TCP windows to categorical, add hurdle zero-indicators + delta packet-length reparameterization, and enforce strict PFIR rejection in `SyntheticSampleFilter`.
2. **Manifold Filter Upgrade:** Add the `signed_log1p` local $k$-NN support gate to `SyntheticSampleFilter`.
3. **Training & Architecture Upgrade:** Replace `30x` SMOTE-NC with mild `2x–3x` structure-preserving augmentation (or shared pretrain + fine-tune) with validation early stopping, and benchmark **ARF / ForestDiffusion / TabDDPM**.
