Reading notes

  • Real and synthetic data contain attack rows only (no Normal/Benign), so Utility is measured as attack-type classification (9 classes); detection (DR/FAR) is not measured.
  • The test set is always real data (15884 rows), split by groups of identical rows from train (63562 rows); synthetic data never enters the test set.
  • Privacy (DCR vs holdout) is only meaningful if the generators were not trained on the holdout rows. If CTGAN/TVAE were trained on the full original file, closer_to_train_rate is biased — confirm how data was split before generation.
  • Variants ros_10k / smote_* = generator trained on oversampled data, so they inherit ROS copies / SMOTE interpolations.
  • OVERSAMPLE = the original ROS/SMOTE files. They include the real data, so only generated rows are kept (real rows subtracted by multiplicity). Rows identical to a test row are removed for every generator (see holdout_copies_removed). ROS/SMOTE were built on the full original data (including test), so indirect leakage remains: SMOTE interpolates from test rows, ROS copied test rows (removed). OVERSAMPLE only adds rare classes, so its TSTR covers a few classes only — compare mainly on TR+S.
  • Each number is a single run (seed 42); differences below ~0.01 macro-F1 are not conclusive.
  • Not computed: FID/MMD, MIA, Differential Privacy (not applicable to standard CTGAN/TVAE).
